# RitesDev, Take Two

**August 22, 2026**

I'm starting over with the RitesDev website.

After looking back at what I had built, I realized something pretty quickly: the website looked lacking and outdated. It worked, but it didn't really feel like the website I wanted RitesDev to have.

So I'm rebuilding it.

## Building Version 2

This time, I'm putting a lot more into the site instead of just getting the basic pages working.

I'm adding more content formatting throughout the website, along with things like tags and tag filtering for the blog.

The blog is also getting a much better structure. I'm using `.mdx` files for the posts, which lets me load and render the blog content for the user instead of treating every post like a separate page I have to build manually.

I'm also adding the other pages I want RitesDev to have.

Basically, I'm getting most of the actual website built this time instead of stopping at the basic structure.

## Making the blog feel like a real blog

The blog is probably the part I'm having the most fun with right now.

I'm adding tags so posts can be organized by topic, along with filtering so someone can actually find posts about a particular subject.

I'm also working on how the content is formatted and displayed.

There are still plenty of things I want to change, but it is starting to feel much more like an actual blog instead of a collection of Markdown files sitting behind a webpage.

## Making the data global

I'm also starting to think more about how the website stores information.

I'm slowly moving things toward being global instead of having the same information repeated throughout different parts of the site.

I've started making a `/const/content` folder for things like the website name, contact information, and blog post files.

The management apps are also coming along pretty well.

I'm continuing to work on the beta editor while I build the website, and I'm starting to make the data work more globally between everything.

It's still a little messy, but I'm getting closer to having the different parts of RitesDev actually work together.

## Where I'm at

I'm pretty happy with this version.

RitesDev definitely isn't ready yet, but the blog is starting to look good, and the beta editor is coming together nicely.

There's still a lot to figure out, especially with how everything is going to work together as the project gets bigger.

But at least this time, I'm starting to feel like I'm actually building the RitesDev website and blog I had in mind.

Now I just need to keep going.
