# Finding a Home for Shared Website Details

As the site grows, I notice information that shows up in more than one place.

The name of the business, contact details, and other shared information shouldn't have to be copied into a bunch of separate pages. If I change something in one place and forget another, the website can start disagreeing with itself. This is an obvious detail for me to consider…

## Make common information easier to manage

I move shared details toward a common content area. The parts of the site that need the same information can read it from one source.

This isn't a finished architecture yet. I'm still figuring out which information is truly shared and how to keep the files straightforward to edit.

## Small decisions matter later

It is tempting to postpone this kind of cleanup while the website is still small. But these choices affect how easy it is to change the site once there are more pages and tools around it.

I build enough structure to avoid needless repetition while keeping the project understandable to me. That's a balance I keep adjusting as RitesDev gets bigger.
