# Building a Launcher for My Own Tools

I make small apps to help manage RitesDev, and soon I have several different things to open.

I have a blog manager, a website content editor, and the tools I use to work on the site itself. Building each tool separately makes sense at first, but switching between them becomes its own little chore.

## One place to start

I start working on a RitesDev launcher that brings some of these tools together. The idea is to have one local application where I can open the management apps and get to the parts of the project I use regularly.

It's a practical tool for my own workflow. It doesn't replace the public website, and visitors don't need it. It just makes the behind-the-scenes work easier for me to manage.

## Building the support system too

This is one of the funny things about building a business website: I keep making tools to support the tools that support the site.
