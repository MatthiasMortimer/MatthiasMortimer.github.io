# BlogRites Content Editor

A tiny local web app for editing `src/content/pages/*.md` and `src/content/site.json`
without hand-writing YAML/JSON.

## Run it

From the repo root:

```bash
npm run editor
```

This starts a local server on http://localhost:4555 and opens it in your default browser.

## How it works

- Pick a file from the sidebar.
- The frontmatter fields are turned into a form (text fields, checkboxes, and
  repeatable sections for lists like FAQs, services, or portfolio projects).
- Click **Save** to write the changes back to the original file.
- No content is generated by AI — this only edits the fields you type in.

Everything runs locally; nothing leaves your machine.
