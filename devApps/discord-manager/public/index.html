Server manager

Server layout

Edit a working draft of this server's categories, channels, and roles. Save the draft as often as you like; nothing changes in Discord until you choose Apply setup.

Roles

Manage server roles and member assignments

Existing roles with matching names are reused. The list order is top to bottom; the bot must rank above these roles.

Member roles

New members receive Pending after setup is applied. Assign saved layout roles or approve a member into Network Member.

Categories and channels

Changes apply to the selected server when you choose Apply setup.

Ticket setup

Members open private threads using one of four ticket types. Moderators can triage, close with a resolution note, and deliver an HTML transcript to the ticket log.

Moderator roles
Selected roles can close and triage tickets and are added to private threads.

Ticket types

Mass message
